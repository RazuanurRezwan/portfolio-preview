RAZUANUR RAHMAN — STREAMING-INSPIRED PORTFOLIO

This version adapts the uploaded reference Reel's cinematic streaming-style aesthetic: dark purple/black panels, bold condensed type, pink-red accents, dramatic hero, card-based content, hover elevation and fullscreen work-image viewer. It does not use the Reel creator's identity or images.

Files at repository root:
- index.html
- style.css
- script.js
- assets/ (profile photo, welcome voice, work samples, CV and certificates)

GitHub Pages installation/update:
1. Extract this ZIP.
2. Upload the CONTENTS of this folder to the root of your existing GitHub Pages repository.
3. Replace index.html, style.css, and script.js when prompted.
4. Keep the entire existing assets folder (this package includes your existing portfolio assets).
5. Commit changes to main and wait for Pages deployment.
6. Open https://razuanurrezwan.github.io/?v=stream-style and hard refresh.

Features:
- Responsive dark streaming-inspired design
- Profile photo in the hero card
- IELTS 7.5 and freelance IELTS, TOEFL, PTE, Duolingo and Oxford ELLT trainer content
- Welcome voice button (audible autoplay may be blocked by browser policy)
- Work card hover/lift effect
- Accessible fullscreen work lightbox with previous/next and Escape/arrow-key navigation
- Existing CV and certificate links retained

YouTube is not needed; this is a static site for GitHub Pages.
